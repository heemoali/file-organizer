# File Organizer

A simple Python tool that automatically sorts your files into separate folders based on their type (images, videos, documents, etc.).

## Features
- Sorts files by type (7 categories + Others).
- Works on any folder you choose.
- No external libraries required.
- Works fully offline (privacy-friendly).

## How to Run
1. Make sure Python 3 is installed.
2. Run the script:
   ```bash
   python organizer.py
